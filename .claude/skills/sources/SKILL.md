# /sources — ревизия карты источников

## Шаги

1. Прочитай `CLAUDE.md` и `sources.md`.
2. Открой каждый источник. Отметь: открылся ли, есть ли там что-то за последние три месяца, не сменился ли адрес.
3. Поищи новые источники. Запросы: «Леонид Фёдоров концерт [месяц] [год]», «Леонид Фёдоров [город]», «Fedorov Kruzenshtern [год]», «АукцЫон концерт [год]», плюс города за границей, которых ещё нет в карте. Всё, чего нет в карте, — кандидат.
4. Кандидата добавляй, только если на нём действительно есть анонсы Фёдорова, а не пустая карточка артиста. Укажи уровень доверия и что там публикуется.
5. Мёртвые источники не удаляй. Пометь «не открывается с [дата]».
6. Запиши изменения в `log/ГГГГ-ММ-ДД.md` и ответь Илье в три-пять строк.
