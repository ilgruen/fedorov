# Фёдоров

Агент, который следит за концертами Леонида Фёдорова и присылает новые в Telegram.

## Что здесь

- `sources.md` — карта: где публикуются концерты. Официальный сайт, телеграм, площадки, билетные операторы, зарубежные афиши.
- `concerts.md` — афиша, собранная агентом. В шапке — дата последней проверки.
- `log/` — журналы прогонов, по файлу на день.
- `CLAUDE.md` — инструкции агенту.
- `routine.md` — текст облачного расписания, по которому агент работает сам.

## Как пользоваться

Открыть эту папку в Claude Code (вкладка Code в приложении Claude) и написать `/afisha`. Агент обойдёт источники, обновит `concerts.md` и коротко скажет, что изменилось.

`/sources` — проверить, живы ли источники, и поискать новые.

Можно и без команд: «где он играет в ноябре?», «есть что-нибудь в Израиле?» — агент прочитает файлы и ответит.

## Как это работает само

Раз в день облачное расписание (Routine на claude.ai/code/routines) запускает `/afisha`. Если появился новый концерт, бот присылает одну строку в Telegram: дата, город, площадка, состав, ссылка на билеты. Если нового нет, бот молчит. Журнал каждого прогона лежит в `log/`.

Что для этого нужно: бот от @BotFather, его токен в переменной окружения `TELEGRAM_BOT_TOKEN` у облачной среды, и сеть среды в режиме Full (или Custom со списком из `allowlist.txt`). Подробности в `routine.md`.
